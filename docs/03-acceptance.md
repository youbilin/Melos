# v1.0 验收记录

更新：2026-11-12。只将实际执行过的检查记录为通过。

## 自动化检查

- `cargo fmt --all --check`：通过。
- `cargo test --workspace --locked`：53 个测试通过，1 个长测试显式忽略；音频解码和 seek 使用仓库自带素材，不再依赖环境变量或静默跳过。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`：通过。
- 格式素材：生成的 440 Hz 信号，WAV、FLAC、MP3、AAC/M4A、Vorbis/OGG。
- Gapless：FLAC → MP3 的输出缓冲样本、曲目边界与接缝能量检查通过；不等同于全部真实音频设备场景。
- WAV/FLAC/MP3 一秒素材均解码为准确的 44,100 帧；修复 Symphonia 已裁剪后再次裁剪的问题。
- HTTP：本地服务端验证 Range seek、截断后重试续传，不丢失或重复字节。
- 30 秒断流恢复长测试：本次显式执行通过，实际用时 30.05 秒。
- 收藏：验证专辑使用 `albumId`，服务端拒绝时保留错误与请求标识供 UI 回滚。
- Windows DPAPI：中文测试密码加密/解密通过。
- 播放栏封面：歌曲与专辑封面 ID 不同、搜索结果缺少封面、不匹配详情页等解析回退测试通过；实际图片显示仍需可见界面验收。
- 队列：插入/追加、删除当前/历史、重复歌曲重排、清空待播、空队列和无效操作测试通过。
- 预取编辑：替换/清空已预取歌曲仍保留当前全部剩余样本；暂停不消耗样本；旧解码错误不停止当前播放；连续编辑保留最终顺序。
- 后续播放：结束后追加、四首音频跨越三秒有界缓冲、自动边界推进测试通过；并发测试按实际消耗样本统计，未将模拟回调锁争用静音记为音频样本。
- Seek：切歌后定位实际播放曲目、保留后续列表、编辑后立即 seek、初始化时 seek 不重复当前歌曲，均通过。
- HTTP 取消：编辑队列后取消旧流的断流恢复测试通过；已在执行的阻塞请求仍最多等待当前请求超时（5 秒），随后结束恢复重试。
- 随机/循环：当前与历史保留、重复歌曲与显式编辑恢复顺序、手动下一首跳过单曲循环、模式设置往返、循环音频跨轮次播放及关闭循环保留当前剩余样本，测试通过。
- 快捷键：输入框/IME 不触发播放、方向键 seek 与 Ctrl+方向键切歌区分，测试通过；真实焦点与按键交互仍待验收。
