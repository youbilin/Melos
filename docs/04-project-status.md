## 队列操作

- 歌曲行的“下一首播放”插到当前歌曲后，“加入队列”追加到末尾；点歌曲行直接开始播放该列表。
- 专辑详情的“加入队列”追加整张专辑。
- 播放栏点“队列”，可点选歌曲、拖动到目标行或使用 ↑/↓ 排序、移除歌曲。
- “清空待播”保留当前歌曲及播放历史。移除当前歌曲会选中后继歌曲；没有后继则停止。暂停时移除当前歌曲仍保持暂停。
- 队列播放结束后追加歌曲会开始播放新歌曲；结束后再次点击播放会重新播放当前歌曲。

## 后续顺序

1. **日常播放控制已补齐**：随机播放、单曲/列表循环、键盘快捷键；与队列、预取、自动切歌联动，尚需实际键盘与鼠标验收。
2. **稳定性与真实界面验收**：播放栏封面、队列拖动、媒体键、快速切歌、真实 Navidrome 格式矩阵、两小时播放、设备断开；每个结论写入验收记录。
3. **完整曲库与加载体验**：专辑分页/按需封面加载、长列表虚拟化、磁盘封面缓存和失败重试。
4. **歌单与歌词**：先接通已有歌单 API，完成浏览与编辑，再接歌词显示及同步。
5. **分发完善与 TUI**：Windows 安装包和签名按分发需要安排；TUI 放在桌面核心功能稳定之后。公开发布须另有用户指令。

每个完成且验证的批次提交、推送至私有仓库。不会把未实现的 UI、仅配置的 CI、或未实际执行的验收记为通过。
