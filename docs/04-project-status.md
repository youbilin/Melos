| 终端歌词不居中、无法返回上一级 | 只保证选中行可见；Esc 固定回专辑页 | 终端同步歌词按可视高度居中；Esc 按页面历史逐级返回 |

| 添加音乐源会直接断开当前源 | 设置只有一个连接槽位，连接即覆盖 | 设置页保存多个音乐源，添加只入库；显式切换时才停止播放并连接 |
| 随机只能全库 | 随机固定从全库取歌 | 专辑/艺人多选随机，队列结束按同一范围续抽；终端可标记专辑 |
| 歌曲列表没有排序 | 全部歌曲按服务器返回顺序 | 按艺人 → 专辑 → 碟号 → 音轨排序，缺省项置后 |
| 一首播完不继续，报 decode error | 转码流请求了估算长度，实际响应比估算短，正常结尾被当成断流 | 转码不再请求 `estimateContentLength`；解码器用服务端时长兜底曲尾判断；明显截断仍报错 |

## 队列操作

- 歌曲行的“下一首播放”插到当前歌曲后，“加入队列”追加到末尾；点歌曲行直接开始播放该列表。
- 专辑详情的“加入队列”追加整张专辑。
- 播放栏点“队列”，可点选歌曲、拖动到目标行或使用 ↑/↓ 排序、移除歌曲。
- 长队列滚动后点“定位当前”，回到当前歌曲所在行。
- “清空待播”保留当前歌曲及播放历史。移除当前歌曲会选中后继歌曲；没有后继则停止。暂停时移除当前歌曲仍保持暂停。
- 队列播放结束后追加歌曲会开始播放新歌曲；结束后再次点击播放会重新播放当前歌曲。
